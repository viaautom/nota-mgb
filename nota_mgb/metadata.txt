about=Evaluates the metadata of each layer against the Brazilian Geospatial Metadata Profile (Perfil MGB 2.0, INDE). Shows a 0-100 score (70 points for compliance with the mandatory elements, 30 for quality), a compliance badge and a list of missing or invalid items, in Portuguese, with the reference table of the standard. One click fills in what can be calculated from the layer (extent in degrees, CRS, representation type, encoding, identifier, date, profile) and fixes common invalid values; a guided form with the official code lists covers the rest. Exports ISO 19115-3 XML (validated against the official XSD, same structure as the iso19115-3.mgb schema of the INDE GeoNetwork catalog) and HTML reports, and imports existing ISO 19115-3 or ISO 19139 (MGB 2009) metadata to migrate it to MGB 2.0. Works offline, no API key needed. Developed by Rafael Dantas de Morais (Ibexdev). / Avalia o metadado das camadas segundo o Perfil MGB 2.0 da INDE: nota, pendências, preenchimento automático, exportação XML ISO 19115-3 e migração do MGB 2009.
