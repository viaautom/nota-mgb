description=Scores layer metadata from 0 to 100 against the Brazilian MGB 2.0 profile (INDE), lists what is missing and fills in what can be calculated.
about=Evaluates the metadata of each layer against the Brazilian Geospatial Metadata Profile (Perfil MGB 2.0, INDE). Shows a 0-100 score (70 points for compliance with the mandatory elements, 30 for quality), a compliance badge and a list of missing or invalid items, in Portuguese, with the reference table of the standard. One click fills in what can be calculated from the layer (extent in degrees, CRS, representation type, encoding, identifier, date, profile) and a guided form with the official code lists covers the rest. Works offline, no API key needed. Developed by Ibexdev. / Avalia o metadado das camadas segundo o Perfil MGB 2.0 da INDE: nota, pendências e preenchimento automático.
